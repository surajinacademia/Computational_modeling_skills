## [3.0.0] - 2026-11-18

This is a major release: `research-project-setup` is renamed `repo-rules`, and `schematic-designer` now exports a PDF by default with an SVG only on request. Other skill names, plugin identifiers, and qualified invocations are unchanged.

- Adds [presentation-story](skills/presentation-story/SKILL.md), which writes the beat sheet of a scientific talk as one file, `talk.md`: numbered parts from the opening question to the conclusion, each a bold title (a question or a statement) with a few plain, cited bullets that end in its answer. It includes a [template](skills/presentation-story/assets/talk-template.md), a [worked example](skills/presentation-story/assets/talk-example.md), a [beat-sheet diagram](skills/presentation-story/assets/talk-beat-sheet.svg), and [source notes](skills/presentation-story/references/sources.md) on the guides by Ratcliff, Raj, McConnell, and Stern. It does not build slides; an optional [handoff](skills/presentation-story/references/slidev-handoff.md) describes passing `talk.md` to a separately installed Slidev skill.
- Adds [brainstorming](skills/brainstorming/SKILL.md), a conversation for hard scientific problems: it asks why, investigates the project and the literature, separates facts from open uncertainties and decisions, recommends an approach with its rationale, and stops at the agreed solution without writing files. Its conversation design is adapted from the MIT-licensed Superpowers `brainstorming` skill; see the [third-party notices](THIRD_PARTY_NOTICES.md).
- Redesigns [paper-reproduce](skills/paper-reproduce/SKILL.md) around The Turing Way's matrix (reproducible, robust, replicable, and generalisable), with four targets (a model or method, a claim or hypothesis, a result, or experimental measurements) and three working modes (`human-in-the-loop` by default, `autonomous`, and `guided-learning`). Reproduction, assessment, and application keep equal standing. Each run delivers one Jupyter notebook holding the item list with criteria fixed in advance, the results table, the logbook of decisions, and regeneration instructions; an item that still disagrees after three diagnostic rounds is reported as a disagreement. The decision diagram is redrawn for the three choices.
- Adds the scientific method to [computational-modeling](skills/computational-modeling/SKILL.md): characterization, hypothesis, prediction, and experiment as an iterative process, with one hypothesis-record entry per hypothesis whose prediction and falsifying outcome are fixed before the test. An outcome supports or falsifies a hypothesis within the tested regime; it never proves it. [jupyter-notebook](skills/jupyter-notebook/SKILL.md) and [claim-review](skills/claim-review/SKILL.md) link claims and tests to that record.
- Changes [schematic-designer](skills/schematic-designer/SKILL.md) to export one vector PDF by default; an outlined-text SVG is produced only when requested or when the destination needs one. Workflows that relied on the SVG being written every time must now ask for it.
- Rewrites the descriptions of [hpc-slurm](skills/hpc-slurm/SKILL.md) and [image-analysis](skills/image-analysis/SKILL.md) to say when each skill applies, so that they trigger on cluster runs and microscopy files even when the skill is not named.
- Revises [ruminations](skills/ruminations/SKILL.md): it reviews one chat or several supplied chats, shows the lessons for the user in the chat, and records each agent rule the user approves in the applicable `AGENTS.md`. It no longer writes `my_lessons.md` or `agent_lessons.md`. `/ruminations rule` records one agent rule and nothing else.
- Revises [lets-be-clear](skills/lets-be-clear/SKILL.md): adds the checks "are we clear?", "are you clear?", and "clear?", and hands a hard problem that needs several rounds to `brainstorming`.
- Renames `research-project-setup` to [repo-rules](skills/repo-rules/SKILL.md) and rewrites it around the six lessons of the Good Research Code Handbook, quoted in the handbook's words: each run puts new files in the right folder, makes one commit per piece of related work that says what changed and why, and records each test of a hypothesis in `tests/RECORD.md`. Adds templates for `AGENTS.md`, `README.md`, `model/README.md`, `tests/RECORD.md`, `.gitignore`, and `environment.yml`; removes the separate Git reference. Users of `research-project-setup` invoke `repo-rules` instead.

## [2.2.0] - 2026-11-16

- Expands the public package from ten to fourteen skills by adding [image-analysis](skills/image-analysis/SKILL.md) (calibrated experimental microscopy segmentation, fluorescence, tracking, and traction-force measurements with paired Panel A/B figures and [supplementary methods](skills/image-analysis/references/supplementary-methods.md)), [ruminations](skills/ruminations/SKILL.md) (explicit `/ruminations` session reviews that recap the problem and solution, record rules for the agent in `agent_lessons.md`, and record learning topics and lessons for the user in `my_lessons.md`), [writing-process](skills/writing-process/SKILL.md) (staged scientific writing from notes, outlines, or figure titles using [19 writing lessons](skills/writing-process/references/lessons.md) linked to Michael Levin's essay and slides without redistributing external slide figures), and [claim-review](skills/claim-review/SKILL.md) (critiquing and scoping scientific claims against actual results, figures, and controls along the `L0–L7` claim-support ladder, with optional secondary `story_arc.md` and `outline.md` templates).
