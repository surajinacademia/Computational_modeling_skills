# Learning-dynamics construction vocabulary

This historical asset name preserves compatibility for existing example sources while drawing its palette, typography, stroke sizes, and arrowheads from the shared [Minimalist profile](minimalist.md).

The original construction study drew inspiration from Mandal et al., [Learning dynamical behaviors in physical systems](https://arxiv.org/abs/2406.07856), while the local examples implement an original illustrative learning-and-drift model rather than the paper's data, photographs, or claims.

Arrange imposed motion, learned response, and retrieval in reading order with headings and whitespace (using phase ribbons only for real groupings, without decorative panel cards), placing computed scalar fields beneath clear entities, paths, and annotations.

The Python asset maps compatibility names (`training`, `retrieval`, `blue`, `red`) to the live palette, and the TikZ asset loads `minimalist-profile.sty` with matching aliases (generate the support style with the shared helper and declare both to `render_tikz.py`). Assign scientific meanings explicitly rather than relying on color names. Keep shared role sizes, mandatory CMU text and LaTeX math, native TikZ terminals (preserving inhibition bars and vector lengths), time-encoding opacity, and magnitude color scales; see [worked examples](../tutorials.md) to run both versions.
