# Record of tests

One entry for each test of a hypothesis, newest first. This file is always in source control. An entry is updated until the test is finished.

## [YYYY-MM-DD] — [Short title of the test] ([in progress or finished])

1. **Hypothesis:** [The scientific question and the reason for asking it. What should be seen if the hypothesis holds, and what if it does not.]
2. **Model:** [Model folder, git hash, and the parameters or flags changed for this test.]
3. **Results:** [What was run and what was found, with numbers. For each result: in source control or kept on this computer only, its folder, its size, and whether it can be made again.]
4. **Conclusion:** [What the results mean for the hypothesis. If the test is not finished: the conclusion so far and what remains.]
